# 検証記録

検証日: 2026-11-23（日本時間）。Windows / Node.js 22.22.1 / npm 10.9.4。

## 検証対象

| 機能 | 操作と確認する状態 |
| --- | --- |
| 比較 | 開始、左再生、右へ切替、停止、再再生、終了、左右の波形と状態、5組の進捗 |
| 選択 | 左・右・両方・どちらでもない、連打防止、途中再読込、終了後の復元 |
| 分析 | 5回答の選択人数、タグの提示と選択件数、履歴、新規セッション |
| 関心 | 未送信・片方向送信・相互成立、再読込、写真公開希望、候補非表示と復帰 |
| 録音 | マイク起動、15秒未満拒否、15秒以上プレビュー、30秒自動停止、再録音と取消 |
| 保存 | 録音の再生、再読込、テーマ別保存、非公開初期値、公開希望切替、削除 |
| 設定 | プロフィール入力・保存、希望条件、定位オフの永続化 |
| 例外 | 音声ネットワーク失敗と再試行、保存失敗、マイク拒否、非対応API、画面離脱 |
| レイアウト | 全6画面で360pxの横はみ出し、デスクトップ、キーボード操作、動きを減らす設定 |

## 実行結果

結果は最終検証後に追記する。実機とブラウザエミュレーションを混同しない。

## 実機での残確認

- iOS Safari / Android Chrome の実機はこの作業環境に接続されていないため未検証。
- 信頼された HTTPS URL で実マイクの許可・録音・再生・再起動後の復元を確認する。
- イヤホンによる左右定位・中央再生・音量・読み上げの自然さは聴覚での確認が必要。
- 本番の通信、アカウント、写真の相互公開、AI生成・推薦は初版の対象外。
